## 💡 หัวข้อ / Concept
**ระบบแจ้งเตือนสถานะเครื่องซักผ้าร้านซักผ้าหยอดเหรียญ** พัฒนาขึ้นเพื่ออำนวยความสะดวกให้แก่ผู้ใช้บริการและผู้ดูแลร้าน แสดงสถานะการใช้งานของเครื่องซักผ้าแบบเรียลไทม์ ผู้ใช้งานตรวจสอบจำนวนเครื่องว่างก่อนเดินทางมาร้าน ตรวจสอบสถานะเครื่องที่ตนเองใช้งานอยู่ รวมถึงดูสถานะของเครื่องทั้งหมด (ว่าง / กำลังซัก / กำลังปั่น / พร้อมรับผ้าในอีก 5 นาที / พร้อมรับผ้า) ส่วนผู้ดูแลร้านสามารถอัปเดตสถานะแต่ละเครื่องผ่านระบบได้สะดวก

## 🌍 แนวคิดการนำไปใช้งานจริง
เกิดจากปัญหาที่พบบ่อยในร้านซักผ้าหยอดเหรียญ คือผู้ใช้บริการไม่ทราบว่ามีเครื่องว่างหรือไม่ ต้องเสียเวลาเดินทางไปโดยไม่จำเป็น และผู้ที่กำลังซักผ้าต้องคอยคำนวณเวลาเองเพื่อกลับมารับผ้า ระบบนี้ช่วยลดปัญหาการเดินทางมาแล้วไม่มีเครื่องว่าง ลดเวลารอคอย และช่วยวางแผนการมารับผ้าได้อย่างมีประสิทธิภาพ

สามารถนำไปประยุกต์ใช้กับร้านซักผ้าหยอดเหรียญที่มีหลายเครื่อง และต่อยอดในอนาคตได้ เช่น แจ้งเตือนผ่านแอป/LINE, ระบบจองเครื่องล่วงหน้า, เชื่อมต่อ IoT เพื่ออัปเดตสถานะอัตโนมัติ, แสดงสถิติการใช้งานเครื่อง

## 🎯 Group Learning Outcomes
- **LO1 (เลือกโครงสร้างข้อมูลให้เหมาะสม):** แยกแยะว่าอะไรควรเป็น mutable/immutable — สถานะเครื่องที่เปลี่ยนตลอดใช้ `dict` ส่วนข้อมูลคงที่อย่างบัญชีแอดมินใช้ `tuple`, สถานะที่ยอมรับได้ใช้ `frozenset`
- **LO2 (จัดการ Collection):** ใช้ set comprehension (`get_available_machines`) กรองและนับเครื่องว่างจาก dictionary
- **LO3 (ควบคุมการทำงานแบบโต้ตอบ):** สร้างเมนูด้วย `while` loop และ `if/elif/else` ให้ผู้ใช้เลือกได้ต่อเนื่องจนออกโปรแกรม
- **LO4 (เขียนโค้ดแบบป้องกันข้อผิดพลาด):** ตรวจสอบหมายเลขเครื่อง/สถานะให้ถูกต้องก่อนเข้าถึงหรือแก้ไขข้อมูลเสมอ (`in` operator, frozenset membership test, `try/except ValueError`)
- **LO5 (บันทึกกระบวนการเรียนรู้):** เก็บ prompt ที่ใช้ถาม AI และการแก้บั๊กไว้ใน `LEARNINGLOG.md`
